## Design decisions

### Colour is never the only signal
Every `PageMode` ships with **texture + text label + (for colour) a four-dot CMYK glyph**. A colour-blind customer identifies the colour page by the CMYK dots + the word "Colour", not by the magenta hue alone. This is wired in `page-thumb.tsx` via the `CmykDots` subcomponent (cyan/magenta/yellow/black dots on a surface chip).

### Long-press handling (PageThumb)
- 500ms timer starts on `pointerdown`.
- `pointermove` > 10px cancels (so scrolling the grid doesn't ring pages).
- `pointerup` clears the timer; if the long-press already fired, the subsequent toggle is swallowed (no double-act).
- `pointerleave` / `pointercancel` clear the timer.
- All timer state in refs — no re-render on every pointer event.

### Flip animation (PageThumb)
The `.page-flip` class (defined in `globals.css`, already `prefers-reduced-motion` aware) is added to the texture layer on toggle and removed on `animationEnd`. This retriggers the keyframe on every tap without remounting the thumb.

### Virtualization (PageStrip)
For 500-page PDFs we use CSS `content-visibility: auto` with `contain-intrinsic-size: 120px 160px` on each cell. This lets the browser skip layout/paint for off-screen cells — simpler than an IntersectionObserver windowing scheme and works without a measurement pass. The scrollbar stays stable because the intrinsic size hint matches the aspect-[3/4] thumb.

### Touch targets
- `UploadDropzone`: 200px min height; `.touch-target` class enforces ≥48px.
- `FileCard`: remove button uses `.touch-target`; retry button is `-my-1 -mr-2` with `touch-target` for a 48px hit area.
- `PageThumb`: `.touch-target` class; renders ~100px wide in a 3-col grid (well above 48px).
- `PageStrip` bulk buttons: `.touch-target`, full-width on narrow viewports.

### Accessibility
- `UploadDropzone`: `role="button"`, `aria-label="Upload files to print"`, `aria-describedby` linking to the formats caption, keyboard handler for Enter/Space, hidden input is `aria-hidden` so screen readers announce the button once.
- `FileCard`: `role="group"` with `aria-label` naming the file + status; progress bar uses `role="progressbar"` with `aria-valuenow/min/max`; remove button `aria-label` names the file.
- `PageThumb`: `aria-label` is dynamic ("Page 12, Colour, selected. Tap to change colour mode."); `aria-pressed` reflects selection; focus-visible ring uses cyan-ink.
- `PageStrip`: `aria-label="Page colour mode selection"`; grid is `role="list"`, cells `role="listitem"`.

### CSS variables
All colours via `var(--color-*)` — no hardcoded hex except the four CMYK dots inside `CmykDots`, which intentionally use the four process-ink CSS variables (`--color-cyan-ink`, `--color-magenta-ink`, `--color-yellow-ink`, `--color-ink`).

## Notes for next agent
- `UploadDropzone` calls `onFiles(File[])` — always an array, even for single picks. The parent should dedupe by name+size if needed.
- `FileCard` accepts an optional `thumbnailUrl` (object URL or remote) — the parent is responsible for revoking object URLs on unmount.
- `PageThumb` long-press fires `onLongPress` with no args; the parent (`PageStrip`) wraps it to pass `pageNumber`. If you use `PageThumb` directly outside `PageStrip`, wire your own page-number closure.
- `PageStrip` does not manage selection state — it only renders `selectedPages` rings. The parent owns the `Set<number>`.
- The `content-visibility: auto` cells are skipped for find-in-page on some browsers; if a future requirement demands Ctrl-F through all 500 pages, swap to an IntersectionObserver virtualizer.
