## Design-system adherence

- **CSS variables only** — every colour references `var(--color-*)`, `var(--radius-*)`, `var(--shadow-*)`, `var(--font-*)`. No hardcoded hex. Tints built with `rgb(R G B / A)` arbitrary Tailwind values derived from the muted/cyan/success/warning/error tokens, and `color-mix(in srgb, ...)` for the toast variant tints.
- **48px touch targets** via `min-h-[48px]` and `.touch-target` helper.
- **16px input text** (`text-base`) on TextField/PhoneField to prevent iOS focus zoom.
- **Reduced motion**: skeleton uses `animate-pulse` + `motion-reduce:animate-none` (and the global `prefers-reduced-motion` clamp in `globals.css` freezes `animate-pulse`); toast entrance is clamped by the same global rule; offline-banner uses Framer Motion `useReducedMotion()` to swap the height slide for a fade.
- **Accessibility**: `<label htmlFor>` pairing, `aria-describedby` for hints/errors, `aria-invalid` on error, `aria-live="polite"` + `role="status"` on toast & offline banner, `role="alert"` on error state, decorative icons `aria-hidden`, skeletons `aria-hidden` (with `SkeletonPageStrip` carrying a single `role="status"` label).
- **Copy**: sentence case, spoken, customer-POV. ErrorState example: "We couldn't load this shop." + "Check your connection and try again." OfflineBanner: "You're offline. Your draft is saved — reconnect to continue." PhoneField inline nudge: "Enter all 10 digits."

## Notes for downstream agents

- These are pure presentational primitives. They expect to be composed into customer route screens (e.g. `/s/[shopSlug]`, `/o/[token]`). No routes were added (per the constraint that only `/` is user-visible).
- `Toast` and `OfflineBanner` are **controlled** — the parent owns open/close and online state. `Toast` keeps `onDismiss` in a ref so parents don't need to memoise the callback.
- `PhoneField.onChange` always fires with **digits-only** (max 10); parents should store the raw digits.
- `TextField`/`PhoneField` are `forwardRef` so parents can focus them programmatically (e.g. scroll-to-error).
